LexiFlow 0.2.0 — 安装说明
==========================

怎么装
------

1. 双击 LexiFlow_0.2.0_x64-setup.exe
2. Windows 可能弹出「Windows 已保护你的电脑」。
   这是没买代码签名证书的正常现象，不是病毒。
   点【更多信息】→【仍要运行】即可。
3. 一路「下一步」装完。
4. 从开始菜单或桌面打开，双击就能用。

不需要注册账号，不需要配置。第一次打开就有四六级大纲词书
（四级 4540 词、六级 2220 词），都能直接学。


需要什么
--------

* Windows 10 / 11，64 位
* 安装时会自动检查 WebView2（微软的网页组件）。
  Windows 11 自带；Windows 10 大多数也有。
  只有缺这个组件的电脑，安装程序才会联网去微软下载。

如果安装时提示缺少 WebView2 又装不上，去这里手动装一下：
https://developer.microsoft.com/microsoft-edge/webview2/


怎么用
------

* 今日计划 —— 首页，点「开始学习」选词书和数量
* 我的词库 —— 浏览所有词书；右上角「导入词书」可以导入自己的词表
* 生词本 —— 手动收藏的难词
* 学习统计 —— 学习记录、进度、强度分布


学习数据存在哪
--------------

全部保存在你自己的电脑上：

  %APPDATA%\app.lexiflow.desktop\lexiflow.db

发音录音缓存在同一目录的 audio 文件夹里。

这些数据只在你本机，不会上传到任何服务器。


发音需要联网
------------

单词发音是真人录音，第一次听某个词会联网下载并缓存。
同一台电脑上再听就不用网了。

没网时会退回 Windows 自带的英文语音，依然能读。


关于更新
--------

这个版本不会自动检查更新（为了不打扰你）。
想升级时，直接装新的安装包覆盖即可，
学习记录会保留。


卸载
----

控制面板 → 程序和功能 → LexiFlow → 卸载。

卸载不会删除学习记录。想彻底清干净，
再手动删掉 %APPDATA%\app.lexiflow.desktop 文件夹。


支持哪些导入格式
----------------

  .txt  .csv  .tsv  .md  .xlsx  .xls  .ods  .pdf

表格里只要有「单词」和「释义」两列就行，列的顺序不限，会自动识别。

注意：PDF 只支持能被选中文字的（有文字层）。
扫描件、截图做的 PDF 读不出文字，需要先用工具转成文字。


遇到问题
--------

先试试：卸载后重新安装一次。

仍然不行的话，把具体的报错信息发给我。
