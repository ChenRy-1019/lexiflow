# 安装说明

## 怎么装

1. 双击 `LexiFlow_0.1.0_x64-setup.exe`
2. Windows 可能弹「Windows 已保护你的电脑」——这是因为安装包没有购买数字签名证书。
   点 **更多信息 → 仍要运行** 即可。
3. 选择安装位置，一路下一步。
4. 装完从开始菜单或桌面打开，**双击就能用**。

不需要注册账号，不需要联网配置。第一次打开就是完整的 52,523 条词库。

## 需要什么

- **Windows 10 / 11**，64 位。
- 安装包会自动检查并安装 WebView2（微软的网页组件，Windows 11 自带）。
  如果安装时它提示要下载 WebView2，保持联网让它装完就好。

## 数据存在哪

学习记录保存在你自己的电脑上：

```
%APPDATA%\app.lexiflow.desktop\lexiflow.db
```

发音录音缓存在同一目录下的 `audio\` 里。

**这些数据只在你本机**，不会上传到任何服务器。

## 发音需要联网

单词发音是真实录音，第一次播放某个词时会联网下载并缓存。
同一台电脑上再听这个词就不用联网了。

没网时会退回系统语音（Windows 自带的英文声音），依然能读。

## 卸载

控制面板 → 程序和功能 → LexiFlow → 卸载。

卸载**不会**删除你的学习记录。如果想要彻底清干净，卸载后再手动删掉
`%APPDATA%\app.lexiflow.desktop` 文件夹。

## 常见问题

**打开就闪退？**
先确认 WebView2 装了。到「控制面板 → 程序」里搜 `WebView2`，
如果没有，去微软官网下 Evergreen 版装上：
https://developer.microsoft.com/microsoft-edge/webview2/

**提示缺少 DLL？**
安装包自带了 VC++ 运行时，正常不会遇到。如果遇到，装一下
「Microsoft Visual C++ 2015-2022 Redistributable (x64)」。

**怎么更新？**
下载新的安装包，直接覆盖安装即可，学习记录会保留。
新版本发布地址：（这里填你的发布链接）

**词库能换成我自己的吗？**
暂时只支持内置词库。自定义导入在计划中。
