Give the plan controls one height and a stable layout

The resume button inherited the base button padding while the start button
used the large variant, so the two sat at different heights. Every control in
the row now shares a 44px height: the buttons, the mode switch and the scope
select.

The row also wrapped differently in a restored and a maximised window, which
made the card change height and pushed the scope selector onto its own line.
The controls now shrink their padding in a narrow card and only wrap as a
group when there is genuinely no room, so the layout matches at both sizes.

Verified at 1000 and 1500 pixel widths.
