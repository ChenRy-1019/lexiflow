Release 0.2.7 to the mirror

0.2.6 shipped with the mirror endpoints already configured, so a learner that
installs this version can update in place from then on. Anyone on 0.2.6 or
earlier still has a build whose manifest points at the GitHub asset, so this
release also carries the downloadable zip for a one-off manual install.

The manifest is regenerated against the v0.2.7 mirror URL and committed to
updates/latest.json. Verified: Gitee served the installer in 10.2 seconds with
a matching hash and signature.
