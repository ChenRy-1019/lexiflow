Mark a misspelt answer by position

The marker aligned the typed answer with the word using the longest common
subsequence. That finds the largest set of matching letters anywhere, which
is the wrong question for a correction: typing `univices` for `universe`
matched the trailing `e` and `s` out of place, marking those correct
letters red while the real mistake stayed green.

The nth letter typed is now compared with the nth letter of the word, so the
marks show which position is wrong. Letters past the end of the word are
wrong by definition.

Four DOM tests cover the reported case, a single substitution, a correct
answer and an over-long answer.
