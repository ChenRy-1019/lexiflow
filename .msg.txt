Release 0.2.1 with a clear download path

The installer now checks whether the binary it is about to replace can be
opened, and stops with instructions to end lexiflow.exe before copying
anything. Installs that used to fail halfway with "无法打开要写入的文件"
now stop up front and say what to do.

The README opens with the download link and says plainly not to use the green
Code button, since downloading the source archive instead of the installer was
the first thing a recipient did.

Verified: a clean install succeeds, and an install over a running copy is
refused before any file is written.
