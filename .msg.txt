Add wordbook importing from common file formats

Learners can now bring their own word list. The backend parses txt, csv,
tsv, md, xlsx, xls, ods and pdf, working out which column holds the headword
and which holds the gloss rather than requiring a fixed layout.

Imported books live in SQLite beside the bundled vocabulary, so an import
survives an upgrade and the built-in books stay intact. A word imported
while the same word exists in a built-in book gets its own entry id, so the
two cards schedule independently.

Every lookup path was taught about the second source: the book list, entry
resolution, session building, the notebook and the choice distractors.

The dialog previews the extraction before writing anything, which matters
most for PDFs, and lets the columns be corrected when the guess was wrong.

Rust tests went from 30 to 75, including 14 that parse real files and 12
that import a book and study from it.
