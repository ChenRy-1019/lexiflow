List each headword once in search results

A word belongs to every wordbook that carries it — `denial` sits in five — and
search appended each copy, so looking up a gloss filled the page with the same
word. Measured: searching 拒绝 returned 67 rows where 20 are distinct.

Hits are now collapsed by headword, case-insensitively, keeping the first copy.
Sorting happens before the collapse so the survivor is stable across runs
rather than depending on the hash map's iteration order.

Four tests cover the collapse, case differences, unrelated words surviving and
the kept copy carrying a usable gloss. `search_any` and `resolve_one` are
now public so the tests can reach them.
