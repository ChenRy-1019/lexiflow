Restore the component stylesheet and make the plan card wrap

Rewriting the stylesheet left 85 component classes undefined, so the home
page collapsed into a single unstyled column and the start dialog rendered as
plain text. The sheet is now complete, and scripts/audit-classes.mjs reports
any class a component uses but the stylesheet does not define; it runs as

pm run audit:css.

The plan card no longer relies on a viewport media query. It wraps with flex,
and a container query turns the side panel into a strip once it has wrapped,
which behaves correctly under display scaling where the card is narrower than
the window.

The default window is smaller so it fits a 125% scaled screen.
