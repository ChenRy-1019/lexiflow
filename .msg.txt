Add a release script that mirrors to Gitee

Publishing now has six steps, several order-dependent: build, upload the
installer, write the manifest against the mirror URL, publish the manifest, and
package the share zip. Doing that by hand invites a stale asset behind a fresh
signature, which is exactly how the mirror first ended up serving an old build.

scripts/release.ps1 runs the checks, build, upload and manifest in order and
prints the one remaining GitHub command, which still needs the author's
approval per AGENTS.md.

publish-gitee.py and manifest.ps1 -BaseUrl are what the script drives.
