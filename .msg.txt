Serve updates from a mainland mirror

The updater could read the manifest but never download the installer: the
manifest is small enough to fetch, while the asset URL inside it points at
GitHub, which times out. A learner therefore saw a failed install for a
version that was published and correct.

Measured here: the GitHub asset URL returned status 000, while the same file
from Gitee downloaded in 10.8 seconds with a matching SHA-256.

manifest.ps1 gains -BaseUrl so the manifest can carry a mirror URL. The
manifest is committed to updates/latest.json and served over Gitee raw, so the
endpoint stays valid across versions instead of naming one tag. Gitee is tried
first, then the ghproxy mirror, then GitHub directly.

scripts/publish-gitee.py uploads a release and its assets to the mirror.
