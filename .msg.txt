Mark the wrong choice and stop the slots growing

The choice mode turned the correct option green but never marked a wrong pick.
The comparison was against `current.entryId`, which is the correct entry, so
the red branch could never match. The picked id is now recorded with the
grade and compared.

The letter slots were sized with `Math.max(word.length, typed.length)`, so a
long typo padded the row and hid how long the word is. Both the spelling and
the dictation branches now show exactly one slot per letter.

Four DOM tests cover the marking and the fixed slot count.
