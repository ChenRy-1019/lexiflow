Fix the blank window when entering practice

The effect that clears a finished session was placed after the early returns
in the render path. React rejects a hook that is not called on every render,
and the error left the whole page blank.

The effect moved above the returns. A real-DOM test now mounts the page and
asserts that it renders a question, has an answer field, and keeps the pinned
toolbar outside the scrolling body, so a hook in the wrong place fails the
build instead of the window.
