Make the installer ready to hand to someone else

The NSIS installer did not check for WebView2, so a Windows 10 machine
without it would fail on launch with no explanation. The bundle now uses the
download bootstrapper: the installer detects the runtime, fetches it silently
when missing, and skips the step when it is already present.

Also adds a Chinese install guide covering the SmartScreen warning, where the
learner's data lives, and the fact that audio needs a connection the first
ime a word is played.


pm run package builds a ~3 MB zip holding the installer and that guide,
which is what actually gets sent to a friend.

The README documents the three steps from send a file up to signed GitHub
Release updates, and states plainly that auto-update is not wired up yet.
