Keep the plan action row on one line at every window size

The row wrapped in a restored window and not when maximised: the scope select
was pushed onto a second line because the controls needed more width than the
main column had. The container queries were keyed to the card, and a card
container cannot size the row's own flex line, so the rules tightened the
buttons but never the gap or the wrapping.

The row is now a grid with the scope select as the only flexible column, and
below 860px the buttons' side padding tightens to keep everything on one line.
Verified by measuring the row at card widths from 700 to 1200px and rendering
at 1194 and 1480.
