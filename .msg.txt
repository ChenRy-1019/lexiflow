Ask for the wordbook and word count before a session starts

Clicking the start button went straight into practice with whatever book
was last selected and a hard-coded twenty words. The start dialog now asks
for the book, the mode, the scope and the word count in one place, and
remembers the answer so the next session is a single click.

The dialog opens from the sidebar, the home plan card, the library (with
that book pre-selected) and the notebook. The practice page takes the
chosen book and size and also offers the size in its toolbar.
