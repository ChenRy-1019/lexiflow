Fix week labels, study timer, immersive mode and practice flow

- The weekly chart labelled its bars as Monday through Sunday while the
  backend returns the seven days ending today, so a Friday appeared under
  the Sunday label. Labels now come from the real dates.
- Practice time is recorded when the page is left, so the counter reflects
  real time instead of the number of answers.
- Starting a session from home or the sidebar hides the chrome (immersive
  mode), and the window controls move to a slim overlay in the corner.
- The home page follows the reference layout: plan on the left with an
  inline mode switch, progress on the right, summary and library below.
- Revealing an answer now requires copying the word first and then typing it
  again from memory, in every mode including dictation, which previously
  locked the field after revealing.
- The four FSRS buttons sit under the answer they grade and show the
  interval each one produces.
- Multiple-choice distractors are drawn at random instead of by position in
  a sorted list, and the correct option is shuffled.
